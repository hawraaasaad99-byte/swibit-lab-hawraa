# Remote Work and Cybersecurity Policy

## 1. Secure Access and Network Infrastructure
- **Virtual Private Networks (VPN):** All employees, developers, and researchers working remotely must utilize the company-mandated enterprise VPN at all times when accessing internal source code repositories, staging databases, or cloud provider consoles (AWS, GCP, Azure).
- **Multi-Factor Authentication (MFA):** Multi-Factor Authentication using hardware security keys or authenticator apps is strictly mandatory across all developer accounts, including GitHub, Jira, CI/CD pipelines, and cloud dashboards. Sharing credentials results in immediate termination.

## 2. Hardware Security and Physical Safeguards
- **Unattended Devices:** Leaving company-issued laptops or workstations unlocked in public spaces, coffee shops, or shared environments is strictly prohibited. Devices must be configured with automatic screen locking mechanisms activated after 5 minutes of inactivity.
- **Disk Encryption:** Full-disk encryption (BitLocker for Windows, FileVault for macOS) must remain active on all devices handling corporate repositories.
- **Public Wi-Fi Safety:** Connecting to unsecured public Wi-Fi networks without an active enterprise VPN tunnel is a direct violation of network security protocols.
